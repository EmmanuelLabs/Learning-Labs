# Lab 001; Post-Installation Optimisation and Driver Integration
## Objective
- Create a recovery point before modifying system kernel files
- Install the compiler and kernel headers required to "build" the virtualbox drivers
## Setup
- System: Fedora 43 Workastation (Guest) on Windows 11 (Host)
- Hardware: Dell Latitude 7400
- Platform: VirtualBox 7.2.6
## Exercise 1: System state preservation (snapshot)
###  Steps Followed
---
1. Navigate to virtualbox menu bar
2. Select Machine > Take snapshot
3. Enter details: 
    *  Name: **Fresh Install-Working**
    *  Description: **Created, Green turtle removed, Blue "V" active**
4. Click OK
## Exercise 2: Preparing the Build environment
### Steps Followed
---
1. Open the fedora terminal
2. Execute the following command to download the development toolchain:
```bash
sudo dnf install -y gcc perl make kernel-devel kernel-headers
```
3. Enter the password for user (Note: characters will not appear).
4. Monitor the DNF package manager as it processes the [237/237] packages
5. Restart the system to initialize the new kernel headers:
```bash
sudo reboot
```

## Outcome
- The virtual machine is now optimized, featuring full screen capabilities and an administrative user account
